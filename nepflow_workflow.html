🚀 NEPFlow Workflow Architecture

Automated Materials Discovery & NEP Force Field Training Pipeline

1
📁

Initialize Project

✓

Organize the project by creating directory structures for configuration, data, and logs. Load experiment parameters from YAML config files, initialize the logging system for debug/info/error output, and validate that all required files and paths exist.

2
🔬

Generate Structures

✓

Layer 1: Composition Grid — Uniformly sample the elemental composition space for unary, binary, and ternary systems using simplex sampling.

Layer 2: Configurational Generators — Generate diverse structures from Materials Project phases, random solid solutions, special quasirandom structures (SQS), and segregated layered configurations.

Layer 3: Perturbations — Expand the dataset with volume scaling, atomic rattling, strain/deformation, vacancies, and interstitials to explore local geometries.

📦 structures/generated/generated_structures.xyz
3
🎯

Select Structures

✓

Algorithm: Farthest-Point Sampling (Greedy Feedforward)

Load the NEP89 foundation model and compute descriptors for all generated structures. Iteratively select the structure furthest from already-selected ones in descriptor space, filter by minimum distance to avoid redundancy, and cap the dataset to stay within computational budget.

📦 structures/selected/selected_structures.xyz
4
⚛️

Run VASP Calculations

✓

Phase 1: Prepare — Validate INCAR templates, identify unique elements, verify POTCAR pseudo-potential files exist, create struct folders, and write POSCAR/POTCAR/INCAR input files.

Phase 2: Submit & Monitor — Use ML to predict optimal GPU/CPU allocation, submit jobs to SLURM, continuously poll for completion or failure, and parse OUTCAR results to extract energies and forces.

Phase 3: OOM Recovery — Detect out-of-memory events, escalate NCORE/KPAR parallelization settings to reduce memory per process, and auto-resubmit with a 7-level retry strategy.

📦 vasp/jobs/struct_XXXX/ (OUTCAR, vasprun.xml, WAVECAR, CHG)
5
🧠

Train NEP Model

✗

Status: Not Yet Implemented

Parse VASP outputs and extract training data from OUTCAR files. Train NEP force field models on the DFT data, store trained weights for reuse, and test model predictions on validation structures.

📦 nep/runs/ (trained_model.txt, training_log.txt)
6
✔️

Validate Model

✗

Status: Not Yet Implemented

Run GPUMD molecular dynamics simulations using the trained NEP model. Compare NEP force predictions against DFT reference calculations, compute error metrics (MAE/RMSE), generate validation reports, and evaluate whether the model is production-ready.

📦 reports/ (validation_report.pdf, error_analysis.csv)
